# Validation record

Version: 0.1.0
Date: 20 July 2026

The default benchmark is synthetic and deterministic. It is intended to validate methodology and software behaviour, not telescope sensitivity or technosignature prevalence.

Required checks:

1. Exact class balance before splitting.
2. Augmented siblings remain in the same train/validation/test split.
3. ON/OFF arrays and derived metadata are finite.
4. The model has fewer than 30,000 trainable parameters.
5. TorchScript export succeeds.
6. Test metrics and candidate rankings are written as machine-readable files.
7. A real-data adapter exists but no real-data result is claimed without a named, archived input.

Reference metrics are generated by `radio-intel-lab demo --config configs/demo.json` and should be regenerated on the user's machine before publication.

## Shipped reference run

- Balanced samples: 400 (80 per class)
- Group-held-out test samples: 60
- Trainable parameters: 6,705
- Test macro-F1: 1.000
- Test balanced accuracy: 1.000
- Candidate-class Brier score: 0.014

The perfect separation is intentionally labelled as a controlled synthetic software check. It must not be quoted as expected real-data performance.
